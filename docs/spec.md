## 2. 流れの全体

```
初回:  S1 ログイン → S2 名前 → (近くに公開中の人がいれば) S4 近くのコーデ / (いなければ) S3 ホーム
登録:  S3 ホーム → [+] → S8 撮影・写真確認・投稿 → S3 ホーム → (処理完了の通知) → S9 アイテムを確認 → S10 公開の設定 → S3 ホーム
見る:  S4 近くのコーデ → (下へ) S5 コーデの詳細 → 服を選ぶ → S6 照合の結果 → S7 着用イメージ
手持ち: S12 マイページ → S11 クローゼット
```

## 3. 各画面

### S1 ログイン
- アプリの起動とログイン状態の復元では、濃いグレーの背景にハンガーと3点の読み込み表示を出す
- 部品: 背景の写真、キャッチコピー [青山]、「Google で続ける」、画面下部の「@Team Wojak」
- Web デモでは S16 に替わる (匿名) [決定]
- 失敗: ログインの失敗を 1 行で出し、もう一度押せる

### S2 名前の設定
- 部品: 名前の入力、決定。あとで変えられる
- 名前は近くの人には見せない [決定]。友達の機能を作らないなら、この画面ごと省ける [青山]

### S3 ホーム
- 引き下げて更新している間は、表示済みの内容を残し、画面上部のインジケーターで進行を示す
- 今日のコーデ (自分の処理後の着姿)、今日見られた回数、今日の着用アイテム
- 今日見られた回数は数だけ。誰が見たかは出さない [決定]
- 上部中央に「WEARBY」のワードマーク、右上に通知ボタンを固定する。スクロールに合わせて今日のコーデのカードが縮み、同じ着姿と閲覧数を細いバナーとしてヘッダーの下に残す
- ベルからアプリ内の通知一覧を開く。未読がある時はベルに印を出し、通知を開くか「すべて既読」で印を消す。フレンド申請の通知からはフレンド画面を開く
- 今日まだ登録していない時は、「探す」の撮影案内と同じイラストとコピーをカードに表示し、右下の矢印から撮影画面を開く。カードが縮むとコピーが「コーデを投稿しよう」に切り替わり、撮影用の矢印と一緒に残る
- ホームにフレンドの今日の公開コーデを表示する。近くにいるかどうかに関係なく見られる。投稿の名前かアイコンを押すと相手のプロフィールを開き、「着用アイテム」から服の詳細を確認できる
- 近くのコーデは下の「探す」から開く

### S4 近くのコーデ
- 1 人 1 画面で全面に着姿。横にめくると次の人。並びは受け取った新しさと近さの順 [決定]
- 出す: 処理後の着姿 (**頭と背景を消した物**) [決定]、受け取ってからの時間 (例 3 分前)
- 出さない: 名前、距離、方向 [決定]
- 下にスワイプすると S5。着姿は同じ位置・大きさのまま、下側のぼかしを広げる
- 未撮影ならイラストと「コーデを投稿して、みんなのを見よう。」を出し、矢印から撮影画面を開く。撮影済みで非公開なら本人のコーデ写真と「コーデを公開して、みんなのを見よう。」を出し、矢印から公開を確認できる
- 公開中に近くのコーデがない時は、ハンガーから画面全体に波紋が広がる空画面を出す。画面下の「再確認」で探し直し、左上の戻るボタンで閉じる
- ライトモードでは、空画面とコーデ閲覧・詳細の背景を白にする
- モックと同じ位置に「いいね」と保存アイコンを表示する。確認用の模擬画面では選択状態のみ切り替える。実データの扱いは 4 節に従う
- 着姿の画面は写真を表示する前に画面の保存を防ぐ (FLAG_SECURE) [決定]。右上のメニューにブロックと通報 [決定]

### S5 コーデの詳細
- 着姿の下に、着用アイテムの切り抜きを横に並べる (アウター・トップス・ボトムス・シューズ)。服の名前・色は Gemini の結果
- 服を 1 つ選ぶと「似たアイテムを検索」ボタンを押せる → S6
- 見てから 30 分は、離れても使える [決定]。30 分を過ぎた着姿は「もう見られません」

### S6 照合の結果 (新規)
- 上に選んだ服。下に、手持ちとの組み合わせを 3 つまで (各組み合わせは手持ちの切り抜きの並び + 理由 1〜2 文)
- 組み合わせが無い時は「手持ちに合う物が見つかりません」と、足りない 1 着の特徴 (例「白の無地のスニーカー」)
- 似た服をもう持っていれば「似た服を持っています」とその 1 着
- 点数は出さず、理由を見せる [決定]
- 各組み合わせに「着てみる」→ S7
- 読み込み中 (数秒〜十数秒): 選んだ服と「手持ちと照らし合わせています」[青山]
- 失敗: 「照合できませんでした」+ もう一度

### S7 着用イメージ (新規)
- 自分の全身写真に、選んだ組み合わせを着せた画像。本人にだけ見える [決定]
- 画像に「AI による着用イメージ」と出す [決定]
- 生成は約 18 秒。待つ間は進み具合を出す [青山]
- 自分の全身写真がまだ無い時は、アプリのカメラで撮る画面へ (ギャラリーからは選べない) [決定]
- 「やり直す」で作り直せる。回数に上限がある [決定]

### S8 写真を撮る・投稿する
- 「コーデを投稿する」→ カメラで全身を撮影 → 写真を確認し、「投稿」または撮りなおす
- 前面と背面のカメラがある端末では、撮影画面の右上で切り替えられる。初めは背面カメラを使い、撮りなおしとアプリに戻った時は選んだカメラを維持する。着用イメージ用の全身写真でも同じ操作を使う
- 「投稿」で処理を開始したらホームへ戻る。サーバは頭を塗り、背景を消し、服を切り抜く。ユーザーは処理を待ちながら別の画面を使える。処理中と失敗を確認できるようにする
- 処理が完了したらユーザーに通知し、通知またはアプリ内の入口から結果を確認できるようにする → S9。通知の許可がない場合もアプリ内で完了を確認できる
- アプリを操作中に処理が完了したら、画面上部に通知を出す。「結果を見る」で未登録のコーデを開く
- Android では、アプリがバックグラウンドで処理結果を受け取った時、通知が許可されていれば端末に通知する。通知から未登録の結果を開ける
- 処理が失敗した時は成功と表示せず、再試行できるようにする。顔が残っていて処理を止めた時は「顔が見えているため公開できません。撮りなおしてください」
- 元の写真はサーバに保存せず、処理中や失敗時に他の人へ公開しない。公開するのは処理後の画像だけで、公開の設定は S10 に従う

### S9 処理結果・アイテムを確認
- 完了の通知後、ユーザーが処理後の着姿とアイテムを確認する。投稿ボタンの直後にはこの画面を挟まない
- 下に切り抜きの一覧。× を押すと確認が出て、同意したら一覧から外す。「アイテムを追加」でクローゼットを検索するか、「新しく追加」からメモだけでコーデに足す
- 服ごとのメモ (ブランド名など、任意)
- 一覧の下に固定の候補欄を置く。確認中は共通の点線アニメーションを出し、完了後は手持ちの画像と名前、または同じ服がない旨を表示する。選んだ服や確認状態が変わっても一覧・メモ・操作ボタンの位置を保つ
- 確認後の「コーデを登録」で今日のコーデを保存する。検出された新しい服は手持ちにも登録する → S10
- ホームから開く登録済みの今日のコーデでも、手持ちやメモの追加・取り外しとメモの編集ができる。「変更を保存」で元の写真を使って更新する

### S10 公開の設定
- 今日の公開: 近くのユーザー / 非公開。**初期は非公開** [決定]
- 公開はその日の 24 時に自動で切れる [決定]
- 公開すると、端末が匿名 ID の発信を始める (Bluetooth の許可を求める)

### S11 クローゼット
- 手持ちの切り抜きの一覧。区分で絞る (すべて・アウター・トップス・ボトムス・シューズ)
- 件数、追加
- 空の時: 「手持ちはまだありません」+ 撮るボタン

### S12 マイページ
- 今日の公開の切り替えは、上部の写真内に置く
- ヘッダー画像を選ぶと、マイページと同じ表示枠で位置と拡大率を調整できる。保存済みの画像も調整できる
- 歯車から設定を開き、マイページのヘッダー画像と表示名を変更できる。Google ログイン時に保存した画像はフレンドにも表示する。以前に端末内だけに保存した画像は、Google ログイン時にサーバに画像がなければ表示範囲と一緒に同期する。ログアウトは確認してから行う
- 設定のダークモードは端末に保存し、次の起動でも引き継ぐ
- Bluetooth と通知の許可は、後で設定画面に置く。マイページには表示しない
- 投稿数・連続記録・友達の数、コーデカレンダーと保存したコーデの入口を表示する
- コーデカレンダーでは記録のある日だけ選べる。選んだ日の処理済み写真と着用アイテムの詳細を表示する

### S15 フレンド
- 下のメニューから開き、名前で絞り込み、受信した申請を承認・辞退できる。各行の「削除」を押すと画面下から確認シートが開く
- 名前かアイコンを押すと、相手のマイページを開く。名前の下に累計の投稿数と連続記録を表示する。今日の公開コーデがない時は「今日の公開コーデはありません」と表示する。設定済みのプロフィール画像は、コーデを非公開にしていても承認済みのフレンドに表示する。下のメニューから別の画面に移れ、フレンドのアイコンで一覧に戻る
- 下へスクロールするとプロフィールの写真ヘッダーが縮み、名前と記録が写真の下側へ寄って上部に残る。プロフィールから他のタブに移る間も下のメニューは固定する。別のタブからフレンドを開き直すと一覧を表示する
- 今日の投稿に着用アイテムがある時は、ホームと同じ一覧を表示する。タイルを押すとその服を選んだ状態で詳細を開き、服の画像・名前・色を確認できる
- ホームとフレンドのマイページでは、投稿画像が画面に見えている時に、その画像を拡大して詳細を開く。画像が画面外の時は通常の画面遷移で開く

### S16 Web デモの入口
- 匿名で入る。見る人は模擬の人物 (AI で作った架空の人物) として動く [決定]
- 画面の上に「デモ: 近くの人の検出は模擬です」と常に出す [決定]
- S4 以降はアプリと同じ画面

## 4. イメージと設計の食い違い [要相談]

| # | イメージ | 設計 | 叩き台の案 |
|---|---|---|---|
| 1 | 近くのコーデに顔と背景が写っている。投稿の時に「顔をぼかす」「背景をぼかす」を選ぶ | 他人に見せる着姿は、頭と背景を常に消す (任意ではない)。concept の安全の考え方の中心 | 消すのは常に。ボタンは置かない。イメージの写真は差し替える |
| 2 | 近くのコーデに「いいね」 | 近くの人への反応は作らない (連絡・フォローを作らない)。いいねはストレッチ | (11/9 に実装、11/10 に記述を実装に合わせた) 近くのコーデのいいねは、相手に「近くの人からいいねが付きました」とだけ届く。誰からかは出さず、返事や連絡の手段は無い。同じ人・同じコーデからの通知は 1 日 1 回。フレンドのいいねは名前を出す |
| 3 | 近くのコーデを「保存」 | 着姿は持ち帰れない。保存できるのは服の情報だけ | 「保存」は服 (切り抜きと名前・色) の保存にする |
| 4 | 似たアイテム → 販売サイトを見る | 外部 EC との連携・型番の特定は作らない。目的は「後悔する買い物を減らす」 | 今回は作らない。代わりに S6 照合 (手持ちで合うか) を主役にする |
| 5 | メールアドレスでのログイン | Google ログインだけ (D4) | Google だけ。11/10 に審査員向けの審査用アカウント (メールとパスワード) だけ足した。一般の登録の口は作らない |
| 6 | 写真の撮り方 (カメラ / ギャラリー) | 着用イメージの自分の写真はカメラだけ | 今日のコーデはギャラリーも可、着用イメージの写真はカメラだけ |
| 7 | ホームの中心が友達の投稿 | 友達・コミュニティはストレッチ | ホームには今日のコーデとフレンドの投稿欄を出す。画面確認用ビルドでは架空のフレンドの投稿を表示する |

## 5. デモの筋書き (30 秒の見せ場)

1. 壇上の発表者 A がジャケットを着て歩く。A の端末はポケットの中で発信している
2. 発表者 B がアプリを開く → S4 に A のコーデ (頭と背景を消した物) が出る
3. 下へめくる → S5 でジャケットを選ぶ → S6 「手持ちのこのパンツとスニーカーで合わせられる」+ 理由
4. 「着てみる」→ S7 に B の着用イメージ (その場で生成。約 20 秒)
5. 一言: 「買う前に、手持ちで確かめられる」

デモの人物 (A と B の着姿・手持ち・全身写真) は AI で作った架空の人物にするか、本人にするかは [要相談] (`docs/tasks.md` の D1)。
