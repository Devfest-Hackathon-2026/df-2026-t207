# プロダクトの全体像 (2026-11-07 時点)

未確定の点は 8 節。

## 1. 一言で

**街で「あの人の服、いいな」と思った時に、話しかけずにその服の詳細が分かり、自分の手持ちで合うかまで確かめられるアプリ。**

## 2. なぜ作るのか

SNS のコーデを載せている人はモデルや高身長の人が多く、自分と見た目もスタイルも違う。同じ服を自分が着ると浮いてしまう。

街ですれ違う普通の人の服なら「これなら自分でも合いそう」と思える。でも、知らない人に「その服どこの?」とは聞けない。

## 3. 使い方

```
【見られる側】
朝、今日のコーデを撮る → AI が服を切り出す → 今日見せてよい服を選ぶ → 持ち歩くだけ

【見る側】
街で服が目に入る → アプリを開く → 近くの人のコーデが並ぶ (顔を隠した今日の着姿) → 見たコーデを選ぶ → 気になる服を選ぶ
   ↓
これは何の服か
   ↓
手持ちで合わせられるか (自分の着用イメージで確かめる)
   ├ 手持ちで作れる → 買わなくて済む
   └ 足りない → その 1 着を、納得して選ぶ
```

## 4. 社会的な意義

**後悔する買い物を減らす。** 買わせないアプリではなく、合わない服を買って着ないままにしてしまうことを減らすアプリ。

| 根拠 | 内容 | 弱点 |
|---|---|---|
| 眠っている服 | 持っている服の 45%、1 人あたり約 24 枚を 1 年間着ていない (環境省) | サンプル数が非公開 |
| 買ったが似合わない | 使っていない理由に「家で着用したら似合わなかった」41.2% (720 人、2016 年) | 古く、フリマ運営の調査 |
| 着こなしが分からない | 着ない理由の約 35% (2 つの調査で 35.3%、34.6%) | 女性だけの企業調査 |

**言わないこと**: 「購入や廃棄を○%減らす」「服の寿命が縮んでいる」(日本の統計で言えない)。

**弱点**: 「モデルのコーデが合わないせいで買い物に失敗している」という因果を直接示す統計は無い。発案者の実感と、当事者への聞き取りで補う。詳細は `docs/research-social-case.md`。

## 5. 既存サービスとの違い

- コーデ SNS (WEAR など): 身長や骨格で探せるが、見るのは投稿された写真。**目の前の服から入れない**
- クローゼットアプリ (Acloset、Fits など): 自分の服の管理が中心
- 試着アプリ (Doppl など): 服を選んだ後の試着。**街で出会った服にはつながらない**

**このアプリの違い**: 街で見た服 → その場で詳細 → 手持ちで確認、までがつながること。ほかにあるかは未確認。

## 6. 安全の考え方

**目で見えている以上のものは渡さない。** 見られるのは、その場で誰でも目にしている今日の服装だけで、本人がそう決めた時に限る。

- 見せるのは顔をぼかし (顔が見つからない時は頭を塗り)、背景を消した今日の着姿と、服の情報。すれ違った人には、名前、プロフィール、過去の投稿は出さない
- 公開は初期オフで、その日ごとに本人が選ぶ
- 見られるのは、自分も今日公開している人だけ (お互いさま)
- 同じ人の着姿は、見る人ごとに 1 日 1 回だけ出す。見えない所にいる特定の人が「まだ近くにいるか」を確かめる使い方を防ぐ
- 距離と方向を出さない。並び順は電波の強さから見た近さの順だけ
- 見た着姿は 30 分で消える。着姿は持ち帰れず、保存できるのは服の情報だけ。画面の保存はなるべく防ぐ
- すれ違った人への連絡、フォロー、過去の投稿への移動は作らない。フレンドは、実際の友人どうしがフレンドコードか QR を交換し、相互に承認した時だけ (すれ違いのカードからは追加できない)。フレンドに見せるのは、その日に公開したコーデだけ (2026-11-09)
- 公開は本人が手で始め、その日の 24 時に自動で切れる。ブロックと通報を用意する
- カメラで相手を照合する機能は作らない

それでも、発信者がその場にいると分かることは消せない。また、写真は目で見るのと違って記録になりうる。完全に防げるとは言わず、どう減らしたかを説明する。

## 7. 機能の優先順位

| 優先 | 機能 |
|---|---|
| **中心の流れ (必須)** | 今日のコーデの登録、顔と背景の処理、服の切り出し、公開の選択、近くのコーデの表示、撮った服が手持ちに入る、手持ちとの照合、足りない 1 着 |
| **見せ場** | 手持ちと合わせた着用イメージ |
| **審査員向け** | 近くの人を模擬できる Web デモ (デプロイ URL)、デモ用のデータ |
| **ストレッチ** | 確かめた記録 (買った / やめた)、保存、似た人を上に並べる、類似検索、いいね・コメント、コミュニティ、トレンド |
| **作らない** | 外部 EC との連携、型番の特定、独自モデルの学習、ポイントと通貨、相手への連絡 |

デモの見せ場 (30 秒):
> 壇上を、ジャケットを着た人が歩く → 発表者がアプリを開くと、その人のコーデが出る → 「手持ちのこの 2 着と合わせられる」→ 自分の着用イメージが並ぶ
