# 近くのコーデの画面確認用素材

画像はすべて AI 生成です。フレンドの投稿の表示確認には `olive.png` と対応する着用アイテムを使用します。

| 素材 | 画像生成時の指定 |
|---|---|
| `olive.png` | オリーブのジャケット、生成りのスウェット、淡色デニム、白のスニーカー |
| `cream.png` | 生成りのブルゾン、紺のボーダーニット、黒のワイドパンツ、アイボリーのスニーカー |
| `denim.png` | インディゴのジャケット、テラコッタのパーカー、ベージュのカーゴパンツ、黒のスニーカー |
| `jacket.png`、`sweatshirt.png`、`jeans.png`、`shoes.png` | オリーブのコーデの着用アイテムを、各1点の切り抜きとして生成 |

内蔵の画像生成ツールで、着姿は頭や肌を含まない全身の服、各アイテムは服だけを指定しました。背景は透過です。
